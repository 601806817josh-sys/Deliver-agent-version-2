# Botchain FAQ（示例 — 请替换为真实资料）

## Botchain 是什么？

Botchain 是面向 Web3 项目的区块链基础设施与交付服务团队，提供链上部署、DEX、浏览器、对接支持等交付能力。

## 怎么接入？

一般流程：
1. 确认项目需求与目标链
2. 提供测试环境与必要参数
3. 联调与 QA
4. 主网部署与验收

具体文档与 API 说明请以项目群内最新交付文档为准。

## 测试环境

测试网/Staging 环境由交付侧按项目单独提供。请在群内 @ 交付负责人说明当前阶段与所需环境。

## 支持网络

支持网络以当前项目合同/交付范围为准，常见包括 EVM 兼容链；细节见项目 Wiki 或群内最新说明。
